# 💰 SpendWise – Expense Tracker

A full-stack expense management application where users can securely track their income, expenses, savings, and monthly budget in one place.

---

## 🚀 Features

- 🔐 User Registration & Login
- 🔒 JWT-based Authentication
- 💰 Add and Manage Income
- 💸 Add, Update, and Delete Expenses
- 📊 Track Total Balance, Income, Expenses, and Savings
- 📈 Monthly Expense Chart
- 🥧 Category-wise Expense Analysis
- 🧾 Recent Transactions
- 🎯 Monthly Budget Tracking
- 👤 User Profile
- 🚪 Secure Logout
- 📱 Fully Responsive Design
- 🌙 Modern Dark UI

---

## 🛠️ Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- React Router
- Lucide React

### Backend

- Node.js
- Express.js
- JWT
- bcryptjs

### Database

- MongoDB
- MongoDB Atlas
